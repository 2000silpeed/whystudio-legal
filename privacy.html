개인정보처리방침

와이스튜디오 업로드 도구 (motion-movie uploader) · 시행일 2026-10-15

1. 누가 쓰는 도구인가

이 도구는 유튜브 채널 와이스튜디오 운영자 한 사람이 자기 채널을 관리하려고 만든 개인용 프로그램입니다. 일반 사용자에게 제공하지 않습니다.

2. 접근하는 정보

운영자가 Google 계정으로 허락한 범위 안에서 다음만 다룹니다.

  • YouTube Data API: 운영자 채널에 영상·썸네일·자막을 올리고, 재생목록에 넣고, 공개 상태와 예약 시간을 바꿉니다. 채널과 영상의 공개 통계(조회수, 좋아요 수, 댓글 수)를 읽습니다.
  • YouTube Analytics API (읽기 전용): 운영자 채널의 시청 시간, 평균 시청 지속, 유입 경로, 구독 증감 같은 집계 통계를 읽습니다.

시청자 개인을 식별하는 정보는 받지 않습니다. Analytics 통계는 유튜브가 주는 집계 수치뿐입니다.

3. 저장과 보관

로그인 토큰은 운영자 컴퓨터에만 저장되고 외부 서버로 보내지 않습니다. 통계 스냅숏은 운영자의 작업 폴더에 저장되며 채널 운영 검토에만 씁니다.

4. 제3자 제공

어떤 정보도 판매하거나 제3자와 공유하지 않으며, 광고에 쓰지 않습니다. Google API에서 받은 정보는 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다.

5. 권한 철회

언제든 Google 계정 → 타사 연결에서 이 도구의 접근 권한을 해제할 수 있습니다. 해제하면 도구는 더 이상 채널에 접근할 수 없습니다.
